# FILM LAB — 빈티지 카메라 PWA

## Windows 실행
1. ZIP을 압축 해제하고 VS Code에서 `film-lab` 폴더를 엽니다.
2. 터미널에서 `python -m http.server 5500` 실행합니다. Python 명령이 안 되면 `py -m http.server 5500`을 사용합니다.
3. Windows 브라우저에서 http://localhost:5500 에 접속합니다. PC 카메라가 있으면 촬영을 테스트할 수 있습니다.
4. 터미널을 종료하려면 Ctrl+C를 누릅니다.

## 아이폰에서 테스트 및 친구에게 공유
- `localhost`는 실행한 PC만을 뜻하므로, PC 주소를 아이폰에 그대로 입력해도 작동하지 않습니다.
- GitHub에 새 공개 저장소를 만들고 이 폴더 안의 프로젝트 파일 전체(index.html, styles.css, app.js, sw.js, manifest.webmanifest, icon-*.png, assets 폴더)를 올립니다.
- Vercel에 로그인하여 GitHub 저장소를 Import합니다. 프레임워크는 Other, 빌드 명령은 비워두고 배포합니다. 발급된 `https://...vercel.app` 링크를 아이폰 Safari에서 엽니다.
- 카메라 권한을 허용하고 촬영합니다. 친구에게 동일 링크를 전달하면 됩니다.
- Safari 공유 메뉴에서 '홈 화면에 추가'를 선택하면 앱처럼 실행됩니다.

## 참고 사항
- 앱 서버에 사진을 업로드하지 않습니다. 사진은 브라우저 안에서 처리합니다.
- 사진 촬영/공유에는 카메라 권한과 HTTPS가 필요합니다. 일부 브라우저에서는 공유 대신 파일 다운로드를 이용해야 합니다.
- 기기/브라우저에 따라 CSS Canvas 필터 성능과 색감이 다를 수 있습니다. 특히 iOS Safari에서 테스트하세요.
- 첫 버전은 영상 프레임 기반 촬영으로, 아이폰 기본 카메라와 같은 원본 사진 해상도·HDR·렌즈 제어를 제공하지 않습니다.
- 카메라 연결이 안 되면 Safari 설정의 카메라 권한, 다른 앱의 카메라 사용 여부, HTTPS 여부를 확인하세요.
- `sw.js`의 캐시 이름(현재 v2)을 v3 등으로 바꾸면 새 배포 때 이전 캐시와 구분할 수 있습니다.

## 구성 (v2.0)
- `index.html` 마크업(Camera · Film Gallery · Photo Preview 3개 화면) · `styles.css` 디자인 · `app.js` 로직
- `assets/` 직접 그린 필름 카메라 SVG 5종과 갤러리용 샘플 일러스트(SVG)
- `sw.js` 캐시 `film-lab-v3`: 새 버전이 활성화되면 이전 캐시를 삭제하고, 열려 있던 화면에는 "새 버전이 적용됐어요" 버튼이 나타납니다.

## 기능
- 촬영 화면에서 하단 필름 스트립을 좌우로 스와이프하면 즉시 필터가 바뀌고, Film Gallery의 선택과 항상 동기화됩니다.
- 필터 5종(Classic 95 / Golden Hour / Blue Memory / Faded Day / Mono 77)은 색 변환, 페이드(블랙 리프트·틴트), 그레인, 비네팅 값이 각각 다릅니다.
- 미리보기·촬영·갤러리 샘플이 같은 `paint()` 함수를 거쳐 색감이 일치합니다. 촬영 해상도는 미리보기와 별개로 원본 기준(최대 2400px)입니다.
- 줌(1x/2x)은 디지털 줌, 노출은 소프트웨어 보정입니다. 후면 플래시는 브라우저가 torch를 지원할 때만 켜지며(iOS Safari 미지원 → 버튼 비활성화), 전면 카메라는 화면 플래시로 대체합니다.
- iOS Safari에는 canvas `ctx.filter`가 없어, 실제로 픽셀이 바뀌는지 검사한 뒤 없으면 픽셀 연산으로 대체합니다. 주소 뒤에 `?nofilter=1`을 붙이면 이 경로를 강제로 테스트할 수 있습니다. 미리보기 해상도는 렌더 시간에 따라 자동 조절됩니다.
- 사진은 서버로 업로드하지 않습니다. iOS Safari에는 사진 앱에 직접 저장하는 API가 없어서, `사진 저장`은 공유 시트의 ‘이미지 저장’을 사용합니다(PC에서는 파일 다운로드).

## 검증 상태
- 확인함(Chromium 가상 카메라, 모바일 뷰포트): 필터 5종 전환·촬영 결과 반영, 스와이프/갤러리 동기화, 전면 카메라 좌우 반전, 두 필터 경로(CSS/픽셀)의 색감 일치, 권한 거부 안내, 가로 화면 레이아웃, 서비스워커 캐시 생성.
- **실기기 미검증**: iPhone Safari에서의 실제 동작(권한 요청, 미리보기 속도, 필터 색감, 공유 시트/이미지 저장, 홈 화면 설치, Safe Area, 화면 회전), 이전 버전(v1/v2 캐시) 설치 사용자의 업데이트 흐름.
